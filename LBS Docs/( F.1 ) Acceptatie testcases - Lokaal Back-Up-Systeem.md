## GAT-01: Gebruikersgemak & Eerste ervaring
#### - GAT-01-01: Omgeving starten via de terminal 

| Veld                    | Inhoud                                                                                                                                                                                                                                                                                                                               |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

| **DOEL**                | De gebruiker kan de omgeving opstarten                                                                                                                                                                                                                                                                                               |

## GAT-02: Beheer van Backup-bestanden
#### GAT-02-01: Aanmaken van een nieuw backupbestand
| Veld                    | Inhoud                                                                                                                                                                                                                                                                                                                                    |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Titel**               | GAT-02-01: Aanmaken van een nieuw backupbestand                                                                                                                                                                                                                                                                                           |
| **DOEL**                | De gebruiker kan backupbestanden aanmaken                                                                                                                                                                                                                                                                                                 |
| **Scenario**            | De gebruiker wilt graag een backupbestand maken om zijn Documenten folder op te slaan.                                                                                                                                                                                                                                                    |
| **Acceptatiecriterium** | Het systeem maakt een nieuw backupbestand aan wanneer de gebruiker een geldige, niet-bestaande naam opgeeft ( ongeldige symbolen: "*!@#$%^&()*" )<br><br>Het aanmaken werkt correct via de1 terminal-argumenten en live-omgeving.<br><br>Wanneer er een naam wordt ingevult die al bestaat laat het programma een duidelijk bericht zien. |

#### GAT-02-02: Toevoegen van bestanden en folders aan een backupbestand
| Veld                    | Inhoud                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Titel**               | GAT-02-02: Toevoegen van bestanden en folders aan een backupb                                                                                                                                                                                                                                                                                                                                                                                     |
| **DOEL**                | bestanden en folders kunnen toevoegen aan een back                                                                                                                                                                                                                                                                                                                                                                                                |
| **Scenario**            | De gebruiker wilt zijn documenten folder graag toevoegen aan een backupbestand.                                                                                                                                                                                                                                                                                                                                                                   |
| **Acceptatiecriterium** | Het systeem voegt `/home/USR/Documents/` toe aan het backupbestand genaamt **backup**. <br><br>Het toevoegen werkt voor losse bestanden en voor volledige mappen.<br><br>Het systeem weigert het pad van het LBS-programma zelf toe te voegen om te voorkomen dat het systeem breekt.<br><br>Bestanden met spaties in de naam zullen niet toegevoegd kunnen worden aan het backupbestand, hierbij toont het systeem aan dat dit niet mogelijk is. |

#### GAT-02-03: Inzien/Raadplegen inhoud backupbestand
| Veld                    | Inhoud                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Titel**               | GAT-02-03: Inzien/Raadplegen inhoud backupbestand                                                                                                                                                                                                                                                                                                             |
| **DOEL**                | De inhoud van een backupbestand kunnen ophalen                                                                                                                                                                                                                                                                                                                |
| **Scenario**            | De gebruiker zal willen weten of zijn documenten folder daadwerkelijk in het backupbestand: "backup" staat.                                                                                                                                                                                                                                                   |
| **Acceptatiecriterium** | Zodra het command : `read <backupbestandsnaam` (of `LBS -rd <backupbestandsnaam`) toont het systeem de inhoud van het backupbestand.<br><br>Als het backupbestand leeg is zal het systeem een bericht tonen dat het bestand leeg is.<br><br>Als het backupbestand niet bestaat zal het systeem een duidelijk bericht laten zien dat het bestand niet bestaat. |

#### GAT-02-04: Bestanden en folders verwijderen uit een backupbestand
| Veld                    | Inhoud                                                                                                                                                                                                                                                                                                                       |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Titel**               | GAT-02-04: Bestanden en folders verwijderen uit een backupbestand                                                                                                                                                                                                                                                            |
| **DOEL**                | Bestanden en folders kunnen verwijderen uit een bestaand backupbestand                                                                                                                                                                                                                                                       |
| **Scenario**            | De gebruiker wilt zijn documenten folder uit het backupbestand halen.                                                                                                                                                                                                                                                        |
| **Acceptatiecriterium** | Het systeem toont aan dat het gewenste bestand/folder successvol is verwijderd.<br><br>Als het gewenste bestand / folder niet in het backupbestand staat laat het systeem zien dat het gegeven bestand / folder er niet in staat.<br><br>Als het gegeven backupbestand niet bestaat toont het systeem dat deze niet bestaat. |

## GAT-03: Uitvoeren van een Back-up

#### GAT-03-01: Een backup uitvoeren 
| Veld                    | Inhoud                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Titel**               | GAT-03-01: Een backup uitvoeren                                                                                                                                                                                                                                                                                                                                                                                        |
| **DOEL**                | Alle bestanden/folders in een backupbestand kopieren naar een backupfolder                                                                                                                                                                                                                                                                                                                                             |
| **Scenario**            | De gebruiker wilt zijn backup uitvoeren om zijn voortgang vast te stellen.                                                                                                                                                                                                                                                                                                                                             |
| **Acceptatiecriterium** | Het systeem laat alle gekopieerde bestanden zien, welke er successvol en niet-succesvol zijn gekopieerd.<br><br>Als het backupbestand leeg is zal het systeem aantonen dat er geen backup wordt gemaakt.<br><br>Als het pad van een folder / bestand niet geldig is toont hij dit aan als niet successvol.<br><br>Als het backupbestand niet bestaat laat het programma zien dat er geen backup uitgevoerd kan worden. |

#### GAT-03-02: Inhoud van een backup ophalen
| Veld                    | Inhoud                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Titel**               | GAT-03-02: Inhoud van een backup ophalen                                                                                                                                                                                                                                                                                                                                                                                                                               |
| **DOEL**                | De successvolle (en niet-successvolle) bestanden en folders kunnen ophalen van een gemaakte backup                                                                                                                                                                                                                                                                                                                                                                     |
| **Scenario**            | De gebruiker wilt de inhoud krijgen van een gemaakte backup, om te kijken of alle bestanden / folders correct zijn opgeslagen                                                                                                                                                                                                                                                                                                                                          |
| **Acceptatiecriterium** | Het systeem toont na het uitvoeren van het commando een duidelijk overzicht van alle opgeslagen bestanden.<br><br>Het ophalen van de inhoud werkt zowel voor een succesvol voltooide backup als in situaties waarin een backup onvolledig of mislukt is (waarbij het systeem aangeeft welke data wel/niet beschikbaar is).<br><br>Als de gebruiker de inhoud opvraag van een niet-bestaande backup/backupbestand dan toont het systeem aan dat de backup niet bestaat. |
