# Inleiding
Dit document beschrijft de technische architectuur en de realisatie van het Lokaal Back-Up Systeem, gebaseerd op de functionele eisen. In het document [[( B.1 ) Functioneel Ontwerp - Lokaal Back-up Systeem]] bevindt zich de informatie over de applicatie. De doelstelling van dit document is om de functionaliteiten/use-cases te realiseren en uit te pakken in een plan van aanpak (PVA). De keuzes gemaakt in dit document zijn gebaseerd op de tijd gegeven voor het project (4 weken).
